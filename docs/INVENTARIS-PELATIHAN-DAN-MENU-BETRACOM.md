# Inventaris Pelatihan dan Referensi Menu Betracom

Dokumen kerja untuk melengkapi katalog dan navigasi Pusat Training dengan membandingkan konten repository terhadap struktur menu publik [Betracom](https://betracom.co.id/).

- Inventaris repository: `src/content/trainings/*.md` pada branch `main`.
- Referensi menu: situs Betracom, diperiksa 19 November 2026.
- Nama berkas pada daftar repo dipertahankan sebagai identitas sumber agar tidak mengarang atau mengubah judul pelatihan.
- Menu Betracom adalah referensi cakupan. Program yang belum ada di repo tidak otomatis berarti harus dibuat tanpa verifikasi isi, skema sertifikasi, dan persyaratannya.

## 3. Fokus perbandingan untuk melengkapi repository

Berikut program/menu Betracom yang belum terlihat sebagai file training dengan nama yang jelas pada daftar Bagian 1. Ini adalah **calon gap untuk diperiksa**, bukan instruksi membuat semuanya sekaligus:

- Teknisi K3 Ruang Terbatas
- Petugas Penyelamat K3 Ruang Terbatas
- Petugas K3 Kimia
- Ahli Muda K3 Lingkungan Kerja
- Damkar Paket DC, DCB, DCBA, CBA, CB, dan BA
- TKBT 2 dan TKPK 1 (repo hanya memiliki file bernama `training-tkpk-2.md`)
- Operator Lift
- Operator Rigger (Juru Ikat) — periksa kecocokan dengan Rigger Kemnaker
- Teknisi K3 PAA
- Ahli K3 Pesawat Angkat Angkut
- Teknisi K3 Bejana Tekan & Tangki Timbun
- Ahli K3 Pesawat Uap Bejana Tekan
- Operator Mesin Produksi & Perkakas 1 (Otomatis)
- Operator Mesin Produksi & Perkakas 2 (Manual)
- Ahli K3 Pesawat Tenaga & Produksi
- Supervisi K3 Perancah
- SMAW Kelas 1, 2, 3 dan GTAW Kelas 1, 2, 3
- Program Manajer Limbah B3 dan Operator Limbah B3
- Sertifikasi lingkungan: PPPA, PPPU, POPAL, PCUA, POPPU, dan program pengelolaan Limbah B3
- Manager Energi dan Manager HR
- HIMU, HIMA, dan HIU
- Pengawas Operasional Madya (POM)
- Sertifikasi BNSP Fireman (periksa apakah sudah tercakup dalam konten Damkar yang ada)
- Perpanjangan lisensi/SIO sebagai kelompok layanan tersendiri

Menu lokasi (Bogor/Jakarta), kategori, berita, artikel, tentang, dan konsultasi perlu dipertimbangkan sebagai navigasi/halaman informasi, bukan otomatis sebagai data pelatihan.

---

## 4. Aturan pemutakhiran

1. Perbarui daftar repository dari berkas aktual `src/content/trainings/`.
2. Periksa ulang situs Betracom sebelum mengubah struktur menu referensi.
3. Cocokkan judul dan ruang lingkup sebelum menambah program; jangan membuat duplikasi hanya karena label berbeda.
4. Jangan mengarang skema sertifikasi, persyaratan, durasi, biaya, jadwal, atau lokasi.
5. Ikuti kontrak konten repository untuk pemisahan data training, brochure, dan schedule.
